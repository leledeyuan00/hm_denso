## For First Configure this template repo

### Make sure the description file is same with the real configuration.

1. Upload the STL model files for robot frame, robotiq, etc. on `hm_denso_description`

2. Edit the xacro file on `hm_denso_description`.

3. Show the edited urdf model by `ros2 launch hm_denso_description view_hm_denso.launch.py`
